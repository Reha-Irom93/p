EXPERIMENT 1
TITLE: Implementation of a Perceptron using Python and NumPy
- AIM: To implement a perceptron from scratch, train it on a linearly separable dataset and visualize the decision boundary.
- OBJECTIVES:
  * Understand the structure of a single artificial neuron.
  * Implement the perceptron learning rule.
  * Observe how the decision boundary evolves with training.
- REQUIREMENTS: Python 3, NumPy, Matplotlib, scikit-learn (make_blobs), Jupyter/Colab.
- THEORY:
  * A perceptron computes y = step(w.x + b).
  * Update rule: w = w + eta(t - y)x; b = b + eta(t - y).
  * Decision boundary w1x1 + w2x2 + b = 0 is a straight line.
  * Converges only for linearly separable data (convergence theorem).
  * Cannot solve XOR.
- CONCLUSION: The perceptron classified the linearly separable data with 100% accuracy, and the decision boundary adjusted to separate the two classes. It is limited to linear problems.

EXPERIMENT 3
TITLE: Backpropagation Algorithm from Scratch
- AIM: To implement backpropagation for a one-hidden-layer network on a toy dataset and visualize gradients and weight updates.
- OBJECTIVES:
  * Understand the forward and backward pass.
  * Derive and implement gradients using the chain rule.
  * Visualize loss and gradient behaviour.
- REQUIREMENTS: Python 3, NumPy, Matplotlib.
- THEORY:
  * Forward: Z1 = XW1 + b1, A1 = f(Z1), Z2 = A1W2 + b2, A2 = f(Z2).
  * Backward uses the chain rule, e.g. dL/dW2 = A1^T . dZ2.
  * Sigmoid derivative = s(1 - s).
  * Update: W = W - eta*dL/dW.
  * Random initialization breaks symmetry.
- CONCLUSION: The network learned XOR; loss decreased steadily and gradients shrank near convergence, demonstrating how backpropagation trains hidden layers.

EXPERIMENT 4
TITLE: Comparison of Activation Functions in a Deep Network
- AIM: To train a multi-hidden-layer network with sigmoid, tanh, ReLU and Leaky ReLU and compare convergence speed and accuracy.
- OBJECTIVES:
  * Learn properties of common activations.
  * Compare their convergence and accuracy.
  * Understand vanishing gradients and dying ReLU.
- REQUIREMENTS: Python 3, TensorFlow/Keras, scikit-learn (make_moons), Matplotlib.
- THEORY:
  * Sigmoid: range (0,1), saturates, vanishing gradient.
  * Tanh: range (-1,1), zero-centred, still saturates.
  * ReLU: max(0,x), fast, can die.
  * Leaky ReLU: small slope for negative inputs, avoids dying neurons.
- CONCLUSION: ReLU and Leaky ReLU converged faster than sigmoid and tanh with comparable or better accuracy; sigmoid was slowest.

EXPERIMENT 6
TITLE: Clustering using k-Means and Hierarchical Methods
- AIM: To apply k-means and hierarchical clustering to a real dataset, visualize the clusters and evaluate with the silhouette score.
- OBJECTIVES:
  * Understand unsupervised learning.
  * Implement both algorithms with scikit-learn.
  * Evaluate cluster quality.
- REQUIREMENTS: Python 3, scikit-learn, SciPy, Matplotlib, Iris dataset.
- THEORY:
  * K-means minimizes within-cluster sum of squares; elbow method picks k.
  * Hierarchical (agglomerative) merges clusters bottom-up; shown by a dendrogram; Ward linkage.
  * Silhouette = (b - a)/max(a,b), range -1 to 1.
- CONCLUSION: Both methods grouped the data into meaningful clusters; silhouette scores quantified the quality, with k = 2 or 3 being suitable for Iris.

EXPERIMENT 8
TITLE: Gradient Descent Optimization for Linear Regression
- AIM: To implement gradient descent from scratch and visualize cost convergence.
- OBJECTIVES:
  * Understand cost minimization.
  * Find optimal w and b iteratively.
  * Study the effect of the learning rate.
- REQUIREMENTS: Python 3, NumPy, Matplotlib.
- THEORY:
  * Cost J = (1/2m) * sum((wx + b - y)^2).
  * Updates: w = w - eta*dJ/dw, b = b - eta*dJ/db.
  * Variants: batch, stochastic, mini-batch.
  * Convex cost, so a single global minimum.
- CONCLUSION: The cost decreased monotonically and the learned parameters approached the true values (w=3, b=4), confirming convergence.

EXPERIMENT 12
TITLE: RNN, LSTM and GRU for Sentiment Analysis
- AIM: To implement RNN variants on sequential text data (IMDB) and compare their performance.
- OBJECTIVES:
  * Understand recurrent architectures.
  * Train SimpleRNN, LSTM and GRU models.
  * Evaluate using accuracy and loss.
- REQUIREMENTS: Python 3, TensorFlow/Keras, IMDB dataset, GPU recommended.
- THEORY:
  * RNN: h_t = f(W_x x_t + W_h h_(t-1) + b).
  * Vanilla RNN suffers vanishing gradients.
  * LSTM uses forget, input and output gates with a cell state.
  * GRU uses update and reset gates; fewer parameters.
  * Sequences are padded and embedded.
- CONCLUSION: LSTM and GRU outperformed the vanilla RNN by handling long-term dependencies; GRU trained faster with similar accuracy.
